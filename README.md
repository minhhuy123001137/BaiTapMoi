# 🌐 Portfolio - Trần Lê Minh Huy

## 👨‍💻 Giới thiệu

Xin chào! Tôi là **TRẦN LÊ MINH HUY**, một **kỹ sư thiết kế Web** với niềm đam mê xây dựng những giao diện website hiện đại, trực quan và thân thiện với người dùng.

Đây là dự án **Portfolio cá nhân** được xây dựng nhằm giới thiệu thông tin cá nhân, kỹ năng chuyên môn, các dịch vụ thiết kế website và những kỹ thuật Frontend mà tôi đã thực hành.

Website tập trung vào việc sử dụng **HTML5 và CSS3** để tạo ra giao diện responsive, các hiệu ứng chuyển động và trải nghiệm tương tác hiện đại.

---

## 🎯 Mục tiêu dự án

Dự án được thực hiện với các mục tiêu:

- Xây dựng một Portfolio cá nhân chuyên nghiệp.
- Thực hành HTML5 và CSS3.
- Làm quen với CSS Variables.
- Xây dựng giao diện Responsive cho máy tính và điện thoại.
- Thực hành CSS Animation và Transition.
- Tạo hiệu ứng Dark Mode.
- Xây dựng Hamburger Menu.
- Thực hành Parallax Scrolling.
- Tạo Card Flip Effect.
- Tạo Typing Effect bằng CSS.
- Tạo Skill Bar Animation.
- Xây dựng Floating Action Button (FAB).

## ✨ Các tính năng chính

### 🌙 Dark Mode

Website hỗ trợ chuyển đổi giữa giao diện sáng và tối bằng CSS Variables kết hợp JavaScript để thay đổi class của `body`.

### 📱 Responsive Navigation

Menu điều hướng được thiết kế responsive. Trên màn hình lớn, menu hiển thị theo chiều ngang. Khi chuyển sang màn hình điện thoại, menu được thay thế bằng Hamburger Menu.

### 🍔 Modern Hamburger Menu

Biểu tượng Hamburger được xây dựng bằng CSS và có hiệu ứng chuyển đổi thành dấu `X` khi menu được mở.

### ⌨️ Typing Effect

Hiệu ứng chữ tự động chạy mô phỏng quá trình gõ chữ:

> Tôi là một Web Developer...

Hiệu ứng được thực hiện bằng CSS Animation mà không cần JavaScript.

### 🎴 Card Flip Effect

Thẻ thông tin cá nhân có thể lật 180 độ khi người dùng di chuột vào, giúp hiển thị thông tin liên hệ ở mặt sau.

### 🌄 Parallax Scrolling

Khu vực dịch vụ sử dụng kỹ thuật Parallax Scrolling với `background-attachment: fixed`, tạo cảm giác chiều sâu khi người dùng cuộn trang.

### 📊 Skill Bar Animation

Các thanh kỹ năng được thiết kế với hiệu ứng chạy từ `0%` đến mức độ kỹ năng tương ứng khi trang được tải.

### 📞 Floating Action Button

Nút liên hệ được cố định ở góc màn hình và sử dụng hiệu ứng Pulse Animation để thu hút sự chú ý của người dùng.
